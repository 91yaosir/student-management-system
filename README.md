# 🎓 学生信息管理系统

## 项目简介
这是一个基于 Python 的学生信息管理系统，支持学生的增删改查操作。

## 技术栈
- 语言：Python 3.x
- 开发工具：VS Code
- 版本控制：Git + GitHub
